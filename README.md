# AgriSocial — نسخة GitHub Mobile

هذه النسخة مهيأة للرفع من الهاتف إلى GitHub بدون الحاجة إلى رفع مجلدات.

## لماذا كانت الصفحة بيضاء؟
النسخة الأصلية تعتمد على ملفات محلية:
- `css/style.css`
- `js/app.js`

إذا رفعت `index.html` و`style.css` و`app.js` من الهاتف إلى نفس مستوى GitHub، فلن تكون المسارات `css/style.css` و`js/app.js` صحيحة، فيظهر الموقع بدون تنسيق وقد لا يعمل JavaScript.

## الرفع من الهاتف
1. افتح المستودع في GitHub.
2. اختر **Add file → Upload files**.
3. ارفع **index.html فقط** من هذا المجلد.
4. اعمل Commit.
5. فعّل GitHub Pages من Settings → Pages واختر الفرع الذي رفعت إليه الملف ومجلد `/ (root)`.
6. افتح رابط GitHub Pages.

> هذه النسخة تجمع HTML + CSS + JavaScript داخل `index.html`، لذلك لا تعتمد على مجلدات محلية.

## الخدمات الخارجية
المشروع يستخدم Firebase وCloudinary عبر الإنترنت، لذلك يجب أن يكون الجهاز متصلاً بالإنترنت.


## الإصلاحات في هذه النسخة
- إصلاح الكتابة داخل مربع إنشاء المنشور على الهاتف.
- زر إلغاء/إغلاق التعليقات يرجع مباشرة إلى المنتدى بدون الاعتماد على الرجوع في سجل المتصفح.
- زر **حفظ** الموجود أسفل كل منشور يعمل فعليًا مع Firebase.
- حفظ المنشور من زر الثلاث نقاط يستخدم نفس وظيفة الحفظ.
- تحديث شكل زر الحفظ إلى «محفوظ» عند نجاح الحفظ.
- معالجة النقرات على المنشورات الديناميكية بعد تحميلها من Firebase.


## الإصلاحات النهائية
- صفحة التعليقات أصبحت مستقلة بالكامل ولا يظهر خلفها مربع إنشاء المنشور.
- زر إغلاق التعليقات يعيدك للمنتدى مباشرة.
- زر حفظ الموجود أسفل المنشور يحفظ المنشور ويعرض رسالة «تم الحفظ ✓» وينقلك تلقائيًا إلى المحفوظات.
- تم إزالة خيار الحفظ من قائمة الثلاث نقاط حتى يكون الحفظ من الزر الموجود أسفل المنشور.
- الضغط على اسم/اسم مستخدم صاحب التعليق أو المنشور يفتح ملفه الشخصي كصفحة كاملة.
- الملف الشخصي العام يحتوي على زر متابعة، وعدد المتابعين والمنشورات والإعجابات ومنشورات الشخص.
- عند المتابعة يصل للشخص إشعار: «[الاسم] بدأ بمتابعتك».
- الضغط على إشعار التعليق يفتح التعليقات ويحدد التعليق المقصود، والإشعار بالإعجاب يفتح المنشور، وإشعار المتابعة يفتح الملف الشخصي.
